# Spoonerism

Spoonerism generator: swap the opening sounds of any phrase, get a silliness rating, batch mode, and tongue-twister ladder. Free fun tool.

## Features
- Spoonerism generator with silliness rating for any phrase
- Batch mode: spoonerize a whole list, one phrase per line
- Tongue-twister ladder: re-swap repeatedly and watch it flip
